| `wycheproof/` | ECDSA P-256 (r‖s), secp256k1 (through Ethereum recovery), and Ed25519 verification, including malformed and edge-case signatures | [C2SP/wycheproof](https://github.com/C2SP/wycheproof) `testvectors_v1/` @ `12fd3aaf33eb5fa1f52e026912ee00c054f9d984` | Apache-2.0 |
| `status-list-draft21.json` | Token Status List encodings (1, 2, 4, 8 bits over 2^20 entries) | [draft-ietf-oauth-status-list-21](https://datatracker.ietf.org/doc/draft-ietf-oauth-status-list/21/), Appendix C, JSON encodings | IETF Trust (code components: Revised BSD) |
| `protocol.json` | commitments, inclusion proofs, statements, Ed25519 and P-256 proofs | generated by `generate_protocol.py`; verified independently by `verify_protocol.mjs` | Apache-2.0 (this project) |

`tests/test_conformance.py` and `tests/test_external_vectors.py` run them. The external suite also compares `canonical` with Trail of Bits' [`rfc8785`](https://github.com/trailofbits/rfc8785.py) on random values when it is installed (`dev` extra) and checks SM3 against the GmSSL reference digests. `scripts/check_vectors.sh` runs the Node checks.

To refresh a third-party set, fetch it at a new commit, update the commit here, and run the tests.
